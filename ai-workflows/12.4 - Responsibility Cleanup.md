# Workflow 12.4 — Responsibility Cleanup

The architecture migration is complete.

Simplify responsibilities throughout the engine.

## Goals

* Reduce coupling.
* Improve cohesion.
* Clarify module responsibilities.
* Simplify the overall architecture.

## Tasks

Review every module.

Ensure each module has a single well-defined responsibility.

Reduce knowledge of parser and matcher internals.

Reduce circular dependencies wherever practical.

Simplify public interfaces.

Replace large conditional dispatch structures with centralized dispatch tables or equivalent extensible mechanisms where appropriate.

Consolidate duplicated implementations.

Remove unnecessary abstractions.

Improve consistency across the project.

## Code Quality

While modifying modules:

* Rename variables, functions, modules, and fields for clarity.
* Improve API consistency.
* Simplify module interfaces.
* Reduce implementation complexity.
* Simplify control flow.
* Remove redundant abstractions.
* Remove obsolete helper functions.
* Remove dead modules.
* Remove unused interfaces.
* Remove temporary debugging features.
* Improve comments describing architectural decisions and module responsibilities.

## Validation

* Complete test suite passes.
* Observable behavior is unchanged.

## Deliverables

* Simplified architecture.
* Simplified dispatch.
* Reduced coupling.
* Improved module boundaries.

## Commit

Before committing:

* ensure the project builds
* ensure the complete test suite passes
* ensure module responsibilities are clearly documented

Create a single commit describing the architectural cleanup.
