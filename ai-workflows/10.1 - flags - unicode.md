# Workflow 10.1 — Unicode Flag

Most flag support has already been implemented.

The engine already contains UTF-8 infrastructure. The objective of this workflow is to integrate the existing implementation with the `u` flag.

## Goals

Implement complete support for the `u` flag.

Reuse the existing UTF-8 implementation rather than introducing a new one.

## Tasks

Enable Unicode mode throughout the engine by integrating the existing UTF-8 helpers where appropriate.

This includes, but is not limited to:

- parser
- matcher
- character iteration
- character classes
- sets
- wildcard matching
- boundaries

Use the existing UTF-8 infrastructure (such as `helpers/utf8` and `helpers/string.lua`) wherever applicable instead of duplicating logic.

Ensure ASCII behavior remains unchanged when the `u` flag is disabled.

## Testing

Cover:

- ASCII mode
- Unicode mode
- inline `u` flags
- scoped `u` flags
- regression tests

## Deliverables

- Complete `u` flag support.
- Existing UTF-8 implementation fully integrated.
- Passing tests.
- Updated documentation.

Create a commit describing the implementation of Unicode flag support.
